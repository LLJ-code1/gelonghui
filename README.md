# 格隆汇观点汇总

这是一个本地投研内容处理项目，用来定期整理 Fanbook 圈子里的二次转发观点。

项目的核心不是搭一个前端或后端应用，而是把下面这条流水线跑稳定：

```text
Fanbook 最新流 -> 截图留存 -> OCR/人工识别 -> 结构化记录 -> 日报 -> 作者归档 -> 断点续跑
```

## 触发词

当用户说 `整理一下最新观点`、`整理一下最新的观点`、`整理最新观点`、`更新最新观点` 或 `跑一轮最新观点` 时，默认含义是：启动 Fanbook `最新` 流增量采集，按 `state/checkpoint.json` 扫到上一轮断点，而不是只整理本地已有日报。

如果用户明确说“只看本地已有内容”或“不要打开 Fanbook”，才改成本地整理。

## 当前规则

- 归档日期按实际采集日期，不按截图内部日期。
- 同一天跑多次，都合并进当天日报。
- 截图内部日期只作为元数据。
- 作者归档按 Fanbook 外层发帖人，截图内作者只作为来源备注。
- 每轮从 `最新` 顶部开始，遇到上一轮顶部 checkpoint 停止。
- 素材留存和日报输出同步做，日报必须能追溯到原始截图。
