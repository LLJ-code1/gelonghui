# 格隆汇观点汇总

## 项目定位

本项目用于定期整理 Fanbook 圈子里的投研观点内容。来源是二次转发内容，帖子外层通常没有稳定发布日期，部分日期只存在于截图内部，因此本项目以“采集批次”为主线管理内容。

核心目标：

- 保留原始素材，确保后续可以回看、复核。
- 按实际采集日期归档，不按截图内日期归档。
- 按作者和市场主题拆分观点。
- 每日生成一份可读的观点汇总。

## 当前规则

- 文件归属日期使用采集运行日期。例如 `2026-05-14` 早上和晚上各跑一次，都进入 `2026-05-14`。
- 截图内出现的日期只作为 `inner_date_text` 元数据，不决定归档日期。
- 每轮从 `最新` 流顶部开始扫，遇到上一轮记录的顶部断点后停止。
- 断点优先使用“外层作者 + 截图内作者 + 截图内日期 + 图片 hash/OCR 指纹”的组合。
- 素材留存和日报输出同步做，日报必须能追溯到原始截图。

## 目录结构

```text
docs/
  流程说明.md
  字段说明.md
  断点规则.md
  操作日志.md
  superpowers/specs/
templates/
  item_record_template.json
state/
  checkpoint.example.json
  checkpoint.json        # 本地运行状态，不提交
  seen_items.json        # 本地去重状态，不提交
data/
  raw/YYYY-MM-DD/        # 原始截图、帖子卡片、页面快照
  ocr/YYYY-MM-DD/        # OCR 文本
  structured/YYYY-MM-DD/ # 结构化记录
outputs/
  daily/                 # 每日观点汇总
  authors/               # 按作者累计归档
```

## 每日输出

每日汇总建议包含：

- 今日采集批次
- 今日新增作者
- A股、港股、美股、宏观、个股、组合策略等主题分类
- 按作者汇总观点
- 多作者共识
- 明显冲突观点
- 可复用的客户经理话术
- 原始素材索引

## 下一步

第一阶段先跑人工确认版流程：打开 Fanbook 圈子 `最新` 流，人工/半自动采集新增内容，保存截图和 OCR，再生成结构化记录与日报。流程稳定后，再把采集和整理做成定时任务。
