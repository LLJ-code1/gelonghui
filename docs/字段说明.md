# 字段说明

结构化记录建议使用 JSONL，一条帖子一行。

## 核心字段

| 字段 | 含义 |
| --- | --- |
| `item_id` | 本条内容的稳定 ID，由采集日期、位置、hash 等生成 |
| `batch_id` | 采集批次，例如 `2026-05-14_2100` |
| `collection_date` | 采集归档日期，例如 `2026-05-14` |
| `collected_at` | 精确采集时间，使用 Asia/Shanghai |
| `feed_sort` | 采集列表，默认 `latest` |
| `source_url` | Fanbook 圈子 URL |
| `source_position` | 本轮扫描中的位置，从 1 开始 |
| `outer_author` | Fanbook 帖子外层显示作者 |
| `inner_author` | 截图内部识别出的作者或栏目 |
| `inner_date_text` | 截图内部日期文本，例如 `5月14` |
| `title` | OCR 识别出的标题或首行 |
| `market_tags` | 市场标签，例如 `A股`、`美股`、`宏观` |
| `topic_tags` | 主题标签，例如 `盘前策略`、`业绩点评` |
| `raw_image_paths` | 原始截图路径列表 |
| `ocr_text_path` | OCR 文本路径 |
| `image_hash` | 图片 hash，用于去重 |
| `ocr_fingerprint` | OCR 文本指纹，用于去重 |
| `duplicate_of` | 如果重复，记录原始 `item_id` |
| `status` | 处理状态 |
| `summary` | 单条观点摘要 |
| `viewpoint` | 提炼后的核心观点 |
| `evidence_note` | 原始素材索引或备注 |

## 状态枚举

| 状态 | 含义 |
| --- | --- |
| `captured` | 已保存原始素材 |
| `ocr_done` | 已完成 OCR |
| `structured` | 已完成结构化 |
| `summarized` | 已纳入日报 |
| `duplicate` | 判定为重复 |
| `ocr_failed` | OCR 失败，但保留素材 |
| `needs_review` | 需要人工复核 |

## 作者规则

- `outer_author` 是二道转发者或 Fanbook 外层显示名。
- `inner_author` 是截图中真正观点来源，优先用于观点归档。
- 如果 `inner_author` 为空，则暂用 `outer_author`，并标记 `needs_review`。

## 日期规则

- `collection_date` 决定文件归属。
- `inner_date_text` 只做内容元数据。
- 同一天多批次采集时，日报按 `collection_date` 合并，批次在正文中列出。
