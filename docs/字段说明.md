# 字段说明

结构化记录建议使用 JSONL，一条帖子一行。

## 核心字段

| 字段 | 含义 |
| --- | --- |
| `item_id` | 本条内容的稳定 ID，由采集日期、位置、hash 等生成 |
| `batch_id` | 采集批次，例如 `2026-05-14_2100` |
| `collection_date` | 采集归档日期，例如 `2026-05-14` |
| `collected_at` | 精确采集时间，使用 Asia/Shanghai |
| `feed_sort` | 采集列表，默认 `latest` |
| `source_url` | Fanbook 圈子 URL |
| `source_position` | 本轮扫描中的位置，从 1 开始 |
| `outer_author` | Fanbook 帖子外层显示作者 |
| `inner_author` | 截图内部识别出的作者或栏目 |
| `summary_author` | 用于日报和作者归档的作者，固定等于 `outer_author` |
| `inner_date_text` | 截图内部日期文本，例如 `5月14` |
| `title` | OCR 识别出的标题或首行 |
| `market_tags` | 市场标签，例如 `A股`、`美股`、`宏观` |
| `topic_tags` | 主题标签，例如 `盘前策略`、`业绩点评` |
| `raw_image_paths` | 原始截图路径列表 |
| `ocr_text_path` | OCR 文本路径 |
| `image_hash` | 图片 hash，用于去重 |
| `ocr_fingerprint` | OCR 文本指纹，用于去重 |
| `duplicate_of` | 如果重复，记录原始 `item_id` |
| `status` | 处理状态 |
| `summary` | 单条观点摘要 |
| `viewpoint` | 提炼后的核心观点 |
| `evidence_note` | 原始素材索引或备注 |

## 状态枚举

| 状态 | 含义 |
| --- | --- |
| `captured` | 已保存原始素材 |
| `ocr_done` | 已完成 OCR |
| `structured` | 已完成结构化 |
| `summarized` | 已纳入日报 |
| `duplicate` | 判定为重复 |
| `ocr_failed` | OCR 失败，但保留素材 |
| `needs_review` | 需要人工复核 |

## 作者每日快照字段

`data/author_daily/YYYY-MM-DD.jsonl` 用于驱动作者观点瀑布流和日报作者汇总。它不是单帖原始记录，而是按作者聚合后的当日观点快照。

| 字段 | 含义 |
| --- | --- |
| `author` | 汇总作者，固定使用 Fanbook 外层作者口径 |
| `date` | 观点归档日期，使用采集日期 |
| `batch_ids` | 覆盖的采集批次 |
| `item_ids` | 纳入该作者当日快照的结构化记录 ID |
| `source_status` | 该作者当日证据状态，优先区分 `summarized` 和 `needs_review` |
| `confidence` | 快照置信度，例如 `high`、`medium`、`low` |
| `today_conclusion` | 当日一句话结论 |
| `logic_chain` | 核心逻辑链，保留推理过程，不能只写结论 |
| `macro_context` | 宏观、流动性、指数位置、交易结构等背景 |
| `focus` | 当日关注方向 |
| `asset_mentions` | 个股、公司、指数、产业链、事件、宏观变量等具体提及 |
| `key_numbers` | 价格、指数点位、仓位、日期、止损位等关键数字 |
| `bullish` | 明确积极判断 |
| `cautious` | 谨慎、回避、非主线或待验证判断 |
| `operation` | 操作含义，例如控仓、低吸、止盈、等待确认 |
| `change_vs_previous` | 相比上一轮的变化 |
| `watchlist` | 后续跟踪事项 |
| `source_key_points` | 从原文/OCR中保留的关键要点 |
| `raw_evidence` | OCR、原图和 item_id 证据链 |
| `review_note` | 复核说明 |

`asset_mentions` 的单项建议包含：`name`、`type`、`direction`、`reason`、`action`、`price_note`、`confidence`。如果源材料是 `needs_review`，只能写可确认主题和待复核原因，不能把方向写成强结论。

## 作者规则

- `outer_author` 是 Fanbook 外层发帖人，是本项目的主作者口径。
- `summary_author` 固定等于 `outer_author`，日报和 `outputs/authors/` 都按这个字段汇总。
- `inner_author` 是截图内部识别出的作者、团队或栏目，只作为素材来源元数据。
- 即使截图内部是另一个作者，也不改变归档作者。例如外层是 `王炽`、内层是 `久路`，归档到 `王炽`。
- 如果 `outer_author` 识别不清，才临时使用 `inner_author`，并标记 `needs_review`。

## 日期规则

- `collection_date` 决定文件归属。
- `inner_date_text` 只做内容元数据。
- 同一天多批次采集时，日报按 `collection_date` 合并，批次在正文中列出。
