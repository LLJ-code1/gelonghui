- 结论修正：之前失败主要是沙盒权限/运行上下文问题，不是 Fanbook 图片不可 OCR，也不是 Vision OCR 本身不可用。
- 后续方向：Fanbook 项目应固化为“裁剪单帖截图 -> 授权本地 Vision OCR -> 清洗文本 -> AI 做语义整理”的流程，模型识图只作为 fallback。
