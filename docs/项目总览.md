# 项目总览

## 一句话定位

`格隆汇观点汇总` 是一个本地投研内容处理项目，用来定期处理 Fanbook 里的格隆汇相关内容。

项目现在分成两个二级子项目：

- `文字版本`：整理 Fanbook 圈子 `最新` 流里的观点截图。
- `视频版本`：保存 Fanbook `#视频` 频道里的网盘视频。

两个子项目共享来源和仓库，但流程、输出、日志、checkpoint 必须分开。

## 子项目一：文字版本

### 用途

把 Fanbook 圈子里的二次转发观点，从截图和长图中提取出来，沉淀成可追溯的日报和作者观点瀑布流。

### 数据流

```text
Chrome 读取 Fanbook 圈子最新流
  -> data/raw/YYYY-MM-DD/ 原始截图
  -> data/ocr/YYYY-MM-DD/ 识别文本
  -> data/structured/YYYY-MM-DD/items.jsonl
  -> data/author_daily/YYYY-MM-DD.jsonl
  -> outputs/daily/YYYY-MM-DD_观点汇总.md
  -> outputs/authors/作者名.md
  -> state/checkpoint.json
  -> docs/文字版本/操作日志.md
```

### 核心规则

- 文件归属日期等于实际采集日期。
- 同一天多次采集都进入同一个日期目录和日报。
- 截图内日期只记录为 `inner_date_text`。
- 作者归档按 Fanbook 外层发帖人，截图内作者只作为来源元数据。
- 每轮从 Fanbook `最新` 顶部开始扫，遇到上一轮 checkpoint 后停止。
- 长图、多图、密集文字图必须打开原图或详情图复核后，才能写成强观点。

## 子项目二：视频版本

### 用途

识别 Fanbook `#视频` 频道里的夸克网盘分享链接，把视频保存到用户夸克网盘 `格隆汇/当天日期` 文件夹，并保留保存记录。

### 数据流

```text
Chrome 读取 Fanbook #视频
  -> 识别夸克分享链接
  -> 打开夸克分享页
  -> 选择 全部文件/格隆汇/YY.M.DD
  -> 保存到网盘
  -> data/video_links/YYYY-MM-DD.jsonl
  -> outputs/video/YYYY-MM-DD_保存清单.md
  -> state/video_checkpoint.json
  -> docs/视频版本/操作日志.md
```

### 核心规则

- 只处理 `https://pan.quark.cn/s/` 开头的夸克链接。
- 腾讯会议、其他网盘或非视频链接只记录，不执行保存。
- 保存前必须先确认 `转存至` 目标目录是 `全部文件/格隆汇/YY.M.DD`。
- 页面出现 `保存成功` 且 `已保存至：YY.M.DD` 后，才记录为 `saved_to_target`。
- 视频流程不改动文字观点 checkpoint，不写入文字日报。

## 顶层目录分工

```text
docs/
  项目总览.md
  文字版本/
    流程说明.md
    字段说明.md
    断点规则.md
    建设路线.md
    操作日志.md
  视频版本/
    流程说明.md
    操作日志.md

state/
  checkpoint.json          # 文字版本断点
  video_checkpoint.json    # 视频版本断点

data/
  raw/                     # 文字版本原始截图
  ocr/                     # 文字版本 OCR/摘录
  structured/              # 文字版本结构化记录
  author_daily/            # 文字版本作者每日快照
  video_links/             # 视频版本保存记录

outputs/
  daily/                   # 文字版本日报
  authors/                 # 文字版本作者瀑布流
  video/                   # 视频版本保存清单
```

## 当前重点

- 视频版本刚完成夸克保存试跑，重点保证保存前选对目标目录，并把已保存/重复/失败状态记录清楚。
