# 项目建设路线

## 当前状态

项目已经完成第一轮闭环：

- Fanbook 圈子 `最新` 流人工/半自动采集。
- 首次无断点时，用截图内昨天日期作为停止线。
- 原始截图本地留存。
- OCR 文本目录和结构化记录已建立。
- 每日观点汇总已生成。
- 作者归档已生成。
- GitHub 仓库已同步。

当前项目不是传统前端或后端应用，没有 `npm build` 这类构建命令。它更像一个本地投研内容处理流水线，建设重点是把“采集 -> 识别 -> 结构化 -> 汇总 -> 归档 -> 定时运行”逐步稳定下来。

## 建设原则

- 先保留证据，再做总结。
- 先半自动跑稳，再脚本化。
- 断点以采集顺序为准，不以截图内日期为准。
- 截图内日期只作为内容元数据。
- 每次运行都写操作日志。
- 日报必须能追溯到原始素材。

## 阶段一：半自动稳定版

目标：把每天早晚两次采集跑稳。

要做：

- 使用 Chrome 打开 Fanbook `最新` 流。
- 从顶部开始截图。
- 遇到上次 checkpoint 停止；首次无 checkpoint 时，遇到截图内昨天日期停止。
- 保存原始截图到 `data/raw/YYYY-MM-DD/`。
- 人工/半自动识别截图内容，写入 `data/ocr/YYYY-MM-DD/`。
- 结构化写入 `data/structured/YYYY-MM-DD/items.jsonl`。
- 生成 `outputs/daily/YYYY-MM-DD_观点汇总.md`。
- 更新 `outputs/authors/*.md`。
- 更新 `state/checkpoint.json`。
- 更新 `docs/操作日志.md`。

验收标准：

- 连续两次运行能正确识别新增内容。
- 第二次运行能根据 checkpoint 停止。
- 同一天多次运行能合并到同一个日报。

## 阶段二：OCR 可用版

目标：减少人工识别成本。

当前问题：

- 沙盒内直接运行 Vision OCR 会返回系统错误。
- 授权到沙盒外运行后，`scripts/ocr_images.swift` 和董小姐 `ocr_tsv.swift` 都可以识别 Fanbook 单图。
- OCR 原始结果仍有错字、断行和低置信度问题，需要后续清洗和人工复核。

可选路径：

1. 固化本机 Vision OCR 路径
   - 优点：本地运行，不依赖外部服务。
   - 风险：需要明确授权在沙盒外调用 macOS Vision；输出仍需清洗。

2. 使用截图裁剪 + 模型识图作为 fallback
   - 优点：对长图、中文截图、混合排版更鲁棒。
   - 风险：消耗 token，需要控制输入规模。

3. 保留人工复核作为 fallback
   - 优点：第一阶段最稳。
   - 风险：效率较低。

推荐：

- 先把“截图裁剪 + 本地 Vision OCR + 清洗”固化为默认路径。
- 模型识图只处理 OCR 失败、作者不清、多图不完整和语义复核。
- 所有 OCR 结果都必须保留原图索引。

## 阶段三：采集脚本化

目标：减少重复操作。

模块建议：

```text
scripts/
  collect_fanbook.py          # 采集入口，管理批次和文件路径
  checkpoint.py               # 断点读取、匹配、更新
  normalize_items.py          # 结构化字段、去重、作者归一
  build_daily_summary.py      # 根据 items.jsonl 生成日报
  update_author_archives.py   # 更新作者归档
```

第一版不追求完整自动滚动和精确卡片截图，可以先让浏览器辅助截图，脚本负责归档、去重、结构化和输出。

## 阶段四：定时运行

目标：固定每天运行。

建议节奏：

- `09:00`：早盘前后采集一次。
- `21:00`：晚间采集一次。

运行后输出：

- 当天日报更新。
- 作者归档更新。
- 操作日志追加。
- 如有异常，标记 `needs_review`。

注意：

- Fanbook 登录态失效时不要自动绕过。
- 不发布、发送、删除、上传或修改 Fanbook 内容。
- 只做读取、截图、识别和整理。

## 阶段五：质量提升

目标：让输出更像可用投研资料，而不是截图摘要。

要做：

- 作者别名归一：日报和作者归档按外层作者，截图内作者只作为来源元数据。
- 市场标签归一：A股、港股、美股、中概、宏观、商品、组合。
- 主题标签归一：盘前、复盘、业绩、个股、策略、风险提示。
- 加入共识/冲突检测。
- 加入客户经理可转述话术。
- 对 `needs_review` 条目建立复核清单。
